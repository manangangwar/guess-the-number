📌 Problem Statement

Number Guessing Game

The objective of this project is to develop a simple Number Guessing Game using Python.

In this game, the computer randomly generates a number between 1 and 10. The player has a maximum of 3 attempts to guess the randomly generated number.

After each guess:

- If the player's guess is correct, the player wins and the game ends.
- If the guess is incorrect, the program informs the player that the guess was wrong and displays the number of guesses remaining.
- After 3 incorrect attempts, the player loses and the program reveals the correct number.

The program also includes simple delays and ASCII-art messages to make the game more interactive and enjoyable.

🎯 Objective

The main objective of this project is to practice fundamental Python programming concepts, including:

- Random number generation
- Variables and data types
- Functions
- "while" loops
- Conditional statements ("if", "else")
- User input
- String formatting
- Using built-in Python modules
- Controlling program flow with "break"

📋 Requirements

- Python 3.x
- No external libraries are required.

🎮 Game Rules

1. The computer generates a random number from 1 to 10.
2. The player gets 3 chances to guess the number.
3. Each guess must be an integer.
4. A correct guess results in a win.
5. Three incorrect guesses result in a loss.
6. The correct number is displayed when the player loses.

The user enters a number between 1 and 10 when prompted:

📤 Expected Output

The program displays whether the guess is correct or incorrect.

For an incorrect guess:

💡 Learning Outcome

After completing this project, the developer will have a better understanding of how to create a small interactive Python program using loops, conditions, functions, random numbers, user input, and built-in modules.
